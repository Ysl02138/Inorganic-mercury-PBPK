
README Supplementary material for Lin et al. Inorganic Mercury Salts PBPK model

=========================================

**Overview:**  
The supplementary data include R code (in the folder of **codes**) and datasets (the folder of **datasets**) that can reproduce the modeling and analysis results (in the folder of **outputs**) and visualize plots (in the **plots** folder).  Also, the readers can re-run the whole MCMC analysis (optional) as detailed below.

**Quick Start:**  
The readers can directly duplicate the current results in a timely manner using the authors' generated MCMC outputs.  First, please execute the “iHg.Rproj” file under the parent directory to set up the correct folder/file path.  Once completed, the readers can execute the files under the folder of **codes** in a stepwise fashion to duplicate the current work (e.g., “1_calibration_Human.R”,  “2_MCMC_diagnosis_Human.Rmd”, and so on)  

**MCMC replication analysis (optional – please see the instructions on the last page for details):**  
The readers can also re-run the MCMC analysis using the files provided in **MCMC replication analysis** as an alternative option. The resultant outputs of MCMC sampling are expected to be the same as those offered by the authors.   

================================= Folder contents ===============================
**codes**
This folder contains stepwise R scripts that allow readers to replicate the analysis using the MCMC outputs generated by the authors. Using the human model as an example:
•	1_calibration_Human.R (Step 1):
Performs model fitting using the hierarchical framework—the main analysis—on the human calibration data (see Figure 2C). Similar calibration scripts are available for mouse and rat and follow the same structure (see Figures 2A and 2B).

*** As a supplemental analysis, readers can run the population model (1_calibration_Human_MAP_supplemental_analysis.R) on the human calibration dataset. Similar scripts are available for mouse and rat. The corresponding results for all three species are presented in Supplemental Figures S11–S13.

•	2_MCMC_diagnosis_Human.RMD (Step 2):
Performs post-MCMC diagnostic checks, including:

(a) Posterior distributions of the population means and variances for the scaling coefficient parameters in the human model are presented in Supplemental Table S7. These parameters were exponentiated (e.g., Kabsc = exp(lnKabsC)) to update the PBPK model parameters shown in Table 2. 
Similar calibration scripts were applied to the mouse and rat models, with corresponding posterior distributions for all three species provided in Supplemental Tables S5–S7.

*** Study-level parameter estimates and diagnostic checks were performed and are available on GitHub, but are not included in the Supplemental Materials.

(b) Trace plots of the Markov chains for the posterior distributions of population-level iHg-specific parameters, including the Brooks-Gelman Multivariate Potential Scale Reduction Factors (MPSRF). The results are shown in Supplemental Figures S2–S4 for mouse, rat, and human, respectively. 

(c) Probability density function plots of posterior distributions for population-level iHg-specific parameters. Results are shown in Supplemental Figures S5–S7 for mouse, rat, and human, respectively. 

(d) Correlation matrix for the posterior means of population-level iHg-specific parameters. Results are shown in Supplemental Figures S8–S10 for mouse, rat, and human, respectively. 

*** Correlations for study-level parameters were also performed and are available on GitHub, but are not included in the Supplemental Materials.

(e) Posterior distributions for measurement residual errors in the human model. Similar analyses were conducted for mouse and rat, with results for all three species presented in Supplemental Tables S8–S10, respectively.

•	3_validation_MAP_Human3.R (Step 3):
Evaluates model fit to the human validation data. After completing validation for all three species (mouse, rat, and human), run “3_validation_All.R” to compile all results (see Figure 3).

•	4_gsa_all.R (Step 4):
Conducts global sensitivity analysis of iHg-specific parameters (see Supplemental Figure S14).

•	5_HED_Mouse.R and 5_HED_Rat.R (Step 5):
Estimate human equivalent doses (HEDs) based on the mouse and rat models (see Table 3).


**MCMC replication (Optional)**
Note: This step is optional. The analysis can be fully replicated using the pre-generated MCMC outputs provided by the authors.

However, readers who wish to rerun the MCMC simulations can do so by executing the provided MCSim application (e.g., mcsim.iHgHumanBW.model.exe) and specifying the input and output file names (e.g., iHgHuman_3365.in, with one input file per species per chain).

**datasets**
Contains the original data used in the current analysis. These datasets are the same as those embedded in the R code scripts.

**MCSim**
Contains the source files for the GNU MCSim software, along with related model and input files used for simulations and predictions.

**outputs**
Stores output files generated by the R scripts and datasets. Users may overwrite these files with their own outputs (e.g., iHgMouse_3365.out for mouse simulations; one output file per chain for each species).

**plots**
Includes all plots presented in both the manuscript and the supplemental figures.
